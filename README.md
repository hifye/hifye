🚀 Projetos em Destaque

Elevate


Uma API REST robusta construída em .NET que simula um sistema de gestão de cursos e inscrições. Este projeto demonstra a aplicação de Clean Architecture, CQRS, JWT Authentication, FluentValidation e integração com PostgreSQL/SQL Server para criar APIs escaláveis e de alta performance.

PersonalFinance


Projeto focado em segurança e infraestrutura, utilizando C#, HCL (Terraform) e Docker. Inclui configurações para migrações em banco de dados RDS, gerenciamento de secrets com AWS Secrets Manager e otimização de segurança com ALB.

FinTrack


Um projeto em C# para acompanhamento financeiro, explorando conceitos de gestão de dados e interfaces de usuário.
